# E-MORE website (emore-project.github.io)

Static site published with GitHub Pages (public repo). English, dissemination only (no WPs or members yet).
- Pages are generated: edit `tools/build.py`, run `python3 tools/build.py`, commit the HTML. Styles: `css/style.css`. Options script: `assets/js/a11y.js`.
- **Accessibility is mandatory**: follow `docs/ACCESSIBILITY.md` (WCAG 2.2 AA, contrast script, axe-core, keyboard, 200 % zoom, high-contrast option).
- Acknowledgement/logos: case B (long set, with EU/ESF+). Logos only in the footer and Funding.
- Theme "Slate & Amber"; assets from the project image kit (`imatge_projecte/`).
