# E-MORE project website

Website of **E-MORE – Efficient Models of Multimodal Representations** (PID2025-170489NB-I00), published with GitHub Pages at https://emore-project.github.io.

Static site (plain HTML + CSS, no build step). Pages: `index.html`, `about.html`, `research.html`, `funding.html`. Theme "Slate & Amber"; assets in `assets/`, styles in `css/style.css`.

Content is a first version; work packages and team will be added later.
